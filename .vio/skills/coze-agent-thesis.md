## 1. 学校要求（先读指导手册再动手）
- 手册：`2027届本科毕业设计（论文）指导手册 - 智科.doc`，read_file 可直接抽取全文（约1900行），先 grep 再按行读。
- 顺序：**文献综述合格后才能开题**；开题 2026.10下旬–11下旬，答辩 2027-05-09 前（含二辩）。
- 综述 ≥2000 字；开题正文 ≥3000 字、文献 ≥10；论文文献 ≥10 且外文 ≥2。
- **摘要**：中文 300–500 字、英文约 1200 字符；关键词须在摘要中出现（曾因"检索增强生成"未出现在缩写后的摘要里改为"知识库"）。
- 用学校附件6模板，不照抄参考报告格式（参考模板本身有错误）。
- 老师硬性要求：近几年文献、不引无关文献、要有智能体论文、删 DOI、句末上标引用、GB/T 7714、段落成文不分点、不写做不到的功能、去套话。查重文字复制比 ≤20%，有 AIGC 检测；学校规定 AI 工具只能做辅助（检索、数据处理），不得直接撰写——由作者本人与导师确认如何说明，论文里不出现 AI 撰写标记。
- **答辩**：每人约15分钟、自述约10分钟、3–5名老师、可查阅资料；成绩=指导40%+评阅30%+答辩30%；需带论文、任务书、综述、开题、指导手册；答辩前10天交论文和检测报告。

## 2. 文献：零编造原则 + 知网核对
- 每篇必须在官方页面看到原始条目才收录；`资料/参考文献清单.md` 记录核实URL与状态。
- 外文用 arxiv_search + 期刊/会议官网；中文用期刊官网、龙源期刊网文章编号（含起止页，如"1674-4039-（2024）05-0088-100"）、本期目录转载页。
- 数字论断只用摘要原文（Dahl 法律幻觉"至少58%"取期刊版）。
- **坑**：转载页可能标错刊名（龚善要实际在《东方法学》，东南大学转载页误标《法学论坛》）。
- **坑**：助手不能登录知网（需机构账号）。结束页码查不到时让作者本人去知网：搜篇名 → "引用" → 复制 GB/T 7714 一行，**每条前写论文里的编号**（知网导出自带的 [1] 会混淆）；一致的只回"对"。DOI、`2024,(5)` 写法差异不改。
- 本项目知网核对结论：中文10篇全部一致；龚善要 2024(5):88-100，王禄生 2023,41(4):49-62。张雅堃知网仍为网络首发，以期刊官网卷期页（2026,62(21):55-73）为准。
- **CCL 会议论文（陈旭）知网不收录**，用 ACL Anthology（aclanthology.org/2024.ccl-2.8）核对，不要因知网搜不到而换文献——换成内容不对应的文献会造成引用与正文不符。
- 公开网页找不到"Coze+法律咨询"期刊论文 → 写"尚不多见"，不写"没有"。

## 3. 扣子（coze.cn）平台：踩坑与正确路径
- 国内版 **www.coze.cn**；新版"扣子编程" code.coze.cn 没有知识库/API发布入口，不要在那里建。
- 正确入口：`https://www.coze.cn/space` → 资源库建知识库 → 项目开发 → 创建 → 智能体 → **标准创建**，**单 Agent（自主规划）**。bot_id = 编辑页地址栏 `bot/` 后的数字。
- 技能、MCP、插件（尤其联网搜索）都不要加：会绕过知识库、测试无法归因。
- 知识库：文本类型，自定义分段"换行"、最大长度 800、重叠 0；**文件一条法条一行、条间空行**。
- 发布必须勾选 **API（Agent As API）**，否则 HTTP 200 + JSON `code 4015`；发布后约30–60秒生效。
- 令牌最长30天、只显示一次。积分初始3000，带知识库问答约20–25积分/次。
- 关闭深度思考：首字约40秒→3.7秒。测试前截图确认模型名与思考开关。
- "创建副本"可能报内部错误 → 对照组手动标准创建，人设/参数逐项照抄，只去掉知识库。发布按钮旁红色"!"不代表未发布。
- 正式测试配置：豆包·2.0·pro、Chat Api、精确模式、重复惩罚0、上下文3轮、最大回复4096、深度思考关闭。

## 4. 后端接入 Coze（Spring Boot）
- `POST https://api.coze.cn/v3/chat?conversation_id=...`，stream=true；SSE 取 `conversation.message.delta`(answer)、`completed`、`verbose`(knowledge_recall)、`chat.completed`/`done`、`failed`/`error`。
- **坑**：错误时返回 HTTP 200 + JSON，先判 Content-Type。
- **坑（企业网络）**：`PKIX path building failed` → 启动加 `-Djavax.net.ssl.trustStoreType=Windows-ROOT`（一键启动.bat 已带）。
- 令牌放运行目录的 `application-local.yml`（`optional:file:./application-local.yml`），不进 jar；默认 mock 模式便于联调。
- 线程池：core=max=64（core=8+queue=100 时只有8路并发）。
- 回答末尾来源链接是临时签名URL，会过期，截图要趁早。

## 5. 知识库数据（法律）
- 只用 flk.npc.gov.cn。新接口：`POST /law-search/search/list`（含 `orderByParam`），过滤标题完全匹配且 `sxx==3`，取最新 gbrq；`GET /law-search/download/pc?format=docx&bbbs=...`。
- `build_kb.py` 每段开头带《法律名》第X条（编·章）；`check_kb.py` 校验条号连续。6部法律1706条，最长665字。

## 6. 测试与评判
- 测试集：5类×10题 + 非法律10题；预期条文只取知识库原文，未覆盖的标注（4题）。
- `run_eval.py` 端到端、每题新会话；`stats.py` 统计；功能测试 `func_test.py` 在 mock 实例跑28个用例；性能 `perf_test.py`。
- 评判标准：引用的每条都真实存在 + 转述与原文相符 + 与问题相关；任一处错误或未引条文 → 不正确。
- 评判流程：`make_judge_packet.py` 对齐原文 → 子代理分段评判（库外条文到 court.gov.cn/gov.cn/flk 核实）→ `merge_judge.py`。
- **复核（2026-11-04）**：两个子代理分别复核7道错题和10道抽查正确题，**全部维持**，86.0%/78.0%不变。边界题：第18题（彩礼，如实说查不到，按标准计错）、第44题（风险提示里交强险赔付顺序表述不严谨，非法条引用错误，维持正确；若改判为84.0%）。写进答辩指南Q18。
- 结论口径：知识库组43/50=86.0%，对照组39/50=78.0%，不一致12题(8:4)，符号检验p≈0.39不显著；库外引用21条 vs 53条（11题 vs 34题）→ 重点写"依据可追溯"，不夸大正确率。
- 用户听不懂"复核"时：直接自己做完，再用一两句话说明意思和结果，不要只给操作说明。

## 7. 论文生成与收尾检查
- 生成：`python 资料\thesis_figs.py && python 资料\gen_thesis.py`（自检字数、摘要字数、引用首次出现顺序、外文篇数）。
- 结构：封面 → 声明/授权书 → **目录（独立分节）** → 中文摘要 → 英文摘要 → 第1章（`pgNumType start=1`）… → 参考文献 → 致谢 → 附录。曾出现两个目录（声明分节末尾一个 + 摘要后空目录一个），已合并。
- 检查脚本思路：解析 document.xml 的 sectPr 看 pgNumType/footer PAGE；检查 media 张数、core.xml 无 python-docx、无 thumbnail/customXml/w:vanish、禁用字样为0、图表编号连续且每张被引用。
- **坑**：交付 docx 不要用公司 Word COM 保存（会加敏感度标签，页脚出现 "Internal"）。核对时复制到 %TEMP% 再打开。
- **坑**：`ExportAsFixedFormat` 卡死 → 用 `$d.SaveAs2([string]$pdf, 17)`；Close 可能报错，导出后结束 WINWORD 进程、删副本。
- **坑**：`taskkill /F /IM` 被安全策略拦截 → 用 `powershell Stop-Process`。
- 目录域代码留给用户打开后 Ctrl+A、F9 更新。
- 司法部律师年度统计：官网最新仍为2022年度（65.16万），无更新可替换。

## 10. 协作经验
- 能自动化的都自己做；只有账号、平台点选、签名、知网登录这类必须本人操作的交给用户，并给逐步指引。
- 用户说"听不懂"时不要再解释流程，直接把事做完，结果用大白话说。
- 用户截图/粘贴结果时逐项核对，自己判断错了明确更正（曾把参考文献编号写错一轮，已更正）。
- 并行子代理适合：中外文文献核实、评判复核（错题组/抽查组各一个）；子代理只读，结论自己抽查。
- 活动工作区可能被切到别的项目（如 scheduling-project），读写论文目录前先 request_permissions（session 范围）。
- 删除前确认没有脚本引用（grep），用户复制进来的参考资料在用户同意后才删；指导手册保留。
- Windows 下多行 `python -c` 写成临时脚本；cmd 中文输出乱码不代表失败。
