# 法律咨询智能体 —— 扣子平台搭建步骤（需用本人账号操作）

> 依据：`资料/Coze接入调研.md`（docs.coze.cn 官方文档，2026-11-03）。平台界面可能调整，以实际页面为准。**每一步完成后截图保存到 `智能体/截图/`，论文第4章要用。**

## 第0步：确认账号能力（最先做，决定技术路线）

1. 打开 https://www.coze.cn 登录（建议用手机号注册）。
2. 检查能否创建"智能体"，并在智能体编排页看到 **知识库**、**工作流** 两个区域。
3. 把结果告诉我：
   - A. 可以 → 按下面步骤继续。
   - B. 提示低代码平台不再向新用户开放 → 截图发我，我会按"扣子编程"调整方案（文档原文："扣子开发平台（低代码）不再向新注册用户开放"）。

## 第1步：准备知识库文档（✅ 已自动完成）

`智能体/fetch_laws.py` 已从国家法律法规数据库（flk.npc.gov.cn）下载 6 部现行有效法律原文，放在 `智能体/知识库原文/`，来源记录见 `_来源记录.json`。`build_kb.py` 已把它们整理为每条法条一段，结果在 `智能体/知识库/*.txt`，共 1706 条；`check_kb.py` 已校验条号连续、无遗漏。

| 法律 | 条数 | 公布日期 | 施行日期 |
|---|---|---|---|
| 中华人民共和国民法典 | 1260 | 2020-05-28 | 2021-01-01 |
| 中华人民共和国劳动法 | 107 | 2018-12-29 | 2018-12-29 |
| 中华人民共和国劳动合同法 | 98 | 2012-12-28 | 2013-07-01 |
| 中华人民共和国劳动争议调解仲裁法 | 54 | 2007-12-29 | 2008-05-01 |
| 中华人民共和国消费者权益保护法 | 63 | 2013-10-25 | 2014-03-15 |
| 中华人民共和国道路交通安全法 | 124 | 2021-04-29 | 2021-04-29 |

表中日期均取自国家法律法规数据库的检索结果，即该法律现行有效版本的日期。

**你只需要**：在扣子知识库里上传 `智能体/知识库/` 下的 6 个 txt 文件。

## 第2步：创建知识库

1. 资源库 → 新建 → 知识库，类型选 **文本**，名称"中国法律条文库"。
2. 上传 `智能体/知识库/` 下的 6 个 txt 文件，分段方式选 **自定义**：
   - 分段标识符：**两个连续换行**（每条法条之间是一个空行）。如果界面只能选"换行"，就选换行。
   - 分段最大长度：800。最长的一条法条是 665 字，所以不会被切断。
   - 重叠度：0
3. 处理完成后，抽查几段，确认一条法条没有被切开。

## 第3步：创建工作流"legal_consult_flow"

节点按下表配置：

| 节点 | 配置 |
|---|---|
| 开始 | 输入参数 `input`（String）—— 用户问题 |
| 意图识别 | 输入 `input`；意图：1 劳动用工 2 婚姻家庭 3 合同纠纷 4 消费维权 5 交通事故 6 其他法律问题 7 非法律问题 |
| 选择器 | 若 classificationId = 7 → 分支A；否则 → 分支B |
| 分支A：结束 | 返回文本："我是法律咨询助手，只能解答法律相关问题。请描述您遇到的法律问题，例如劳动纠纷、租房、网购维权等。" |
| 分支B：知识库检索 | Query = `input`；知识库 = 中国法律条文库；召回数量 5；最小匹配度 0.5 |
| 分支B：大模型 | 输入：`question` = input，`category` = 意图识别的 reason/分类，`laws` = 知识库检索的 outputList；系统提示词 = `人设与回复逻辑.md` 中"技能1""限制"部分；用户提示词："问题类别：{{category}}\n检索到的法律条文：{{laws}}\n用户问题：{{question}}\n请严格依据上述条文按格式回答，条文中没有依据的内容不要编造。" |
| 分支B：结束 | 返回文本 = 大模型输出，开启流式输出 |

做完后先用"试运行"测试 3 个问题（劳动、消费、非法律各一个），通过后再 **发布** 工作流。

## 第4步：创建智能体

1. 新建智能体，名称"法律咨询助手"。
2. **人设与回复逻辑**：粘贴 `人设与回复逻辑.md` 全文，并在"技能1"末尾加一句：
   > "回答法律问题时调用工作流 legal_consult_flow。"
3. 工作流：添加 legal_consult_flow。
4. 知识库：添加"中国法律条文库"，调用方式选"自动调用"，并设置无召回时的回复话术。
5. 开场白："您好，我是法律咨询助手，可以为您解答劳动、合同、婚姻家庭、消费维权、交通事故等常见法律问题。请描述您遇到的情况。"
6. 在右侧调试窗口测试，**截图保存**。

## 第5步：发布与令牌

1. 右上角 **发布** → 选择发布平台 → 勾选 **API** → 发布。
2. 记录 bot_id：编排页地址 `.../bot/` 后面那串数字。
3. 进入"API & SDK → 授权"，创建令牌：
   - 优先选**服务访问令牌**，可以长期有效；
   - 如果只能建个人访问令牌，最长 30 天，需要按时续期。
   - 权限勾选：chat、createConversation、getChat、listMessage。
4. **令牌只发给我写进本地后端配置**（`application-local.yml`，已加入 .gitignore），不要发到群里，也不要提交到 Git。
