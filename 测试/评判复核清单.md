## 一、判为不正确的题（全部）

- [x] **第18题** [婚姻家庭] 结婚时给的彩礼，离婚后可以要回来吗？
  - 评判：不正确；理由：未引用任何具体条文（回答称知识库未检索到彩礼相关条文而未作解答；预期本题为知识库未覆盖）；类别：回答识别为彩礼返还问题，未作出与婚姻家庭相矛盾的判断

- [x] **第21题** [合同纠纷] 房东提前收回房子，押金不退，我该怎么办？
  - 评判：不正确；理由：张冠李戴：引用民法典第724条（原文：租赁物被查封扣押、权属有争议、违反使用条件强制性规定等“非因承租人原因致使租赁物无法使用的，承租人可以解除合同”），内容虽与原文相符，但该条规定承租人解除权，与房东提前收房的违约责任及押金返还无关，不能支撑结论；未引用预期的第708条、第577条

- [x] **第27题** [合同纠纷] 装修公司装修质量很差，拒绝返工，我能解除合同吗？
  - 评判：不正确；理由：781条正确；806条为建设工程合同中“承包人”因发包人不履行协助义务等可解除合同的规定（且漏引第1款），方向与本题定作人因装修质量差、拒绝返工请求解除无关，属张冠李戴；未引563条

- [x] **第30题** [合同纠纷] 网上签的电子合同有法律效力吗？
  - 评判：不正确；理由：512条文字与原文一致，但该条规定电子合同交付时间，与“电子合同是否有效”问题不对应；效力结论无条文支撑，未引469/491条

- [x] **第39题** [消费维权] 快递丢件了，快递公司只按运费几倍赔偿，合理吗？
  - 评判：不正确；理由：833条正确；835条仅适用于“因不可抗力灭失”，本题快递丢件非不可抗力，回答据此泛称“已支付运费可要求返还”，属张冠李戴

- [x] **第40题** [消费维权] 在直播间买的商品有质量问题，主播和商家谁负责？
  - 评判：不正确；理由：消法40条引述被篡改：原文“生产者赔偿后，有权向销售者追偿”，回答写成“有权向消费者追偿”；《网络消费纠纷规定（一）》(法释〔2022〕8号)经官方原文核对：第11条实为平台内经营者直播间工作人员虚假宣传责任，与回答所述“直播运营者未尽审核义务”不符；第12条条件被改写；回答所称第13条（平台不能提供直播间运营者信息）实为第14条，条号错误

- [x] **第50题** [交通事故] 交通事故受伤后多久可以申请伤残鉴定？
  - 评判：不正确；理由：《道路交通事故处理程序规定》第49条第1款、第51条文字经gd.gov.cn核实一致，但二者为交管部门委托事故检验鉴定的期限，与当事人申请伤残鉴定时机无关；该规定第50条、第92条明确伤残评定由当事人自行协商委托，回答据此建议“由交管部门委托鉴定”属张冠李戴；《人体损伤致残程度分级》4.2经gov.cn转载核实一致
